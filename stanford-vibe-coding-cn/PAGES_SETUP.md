# GitHub Pages 开启指南（5 分钟）

> 把项目变成一个在线可访问的网站，不用 clone 就能看。

---

## 操作步骤

### 第 1 步：推送代码到 GitHub
先确保你已经按照 `GITHUB_SETUP.md` 的步骤把代码推上去了。

### 第 2 步：打开仓库设置
在你的 GitHub 仓库页面：
- 点顶部的 **Settings**（设置）
- 左侧菜单找到 **Pages**（在 "Code and automation" 分类下面）

### 第 3 步：配置 Pages
1. **Source** 选 `Deploy from a branch`
2. **Branch** 选 `main`
3. 文件夹选 `/ (root)`
4. 点 **Save**

### 第 4 步：等 1-2 分钟
GitHub 会自动构建你的网站。等一会儿刷新页面，顶部会出现一行绿色提示：
> "Your site is live at https://你的用户名.github.io/stanford-vibe-coding-cn/"

### 第 5 步：访问验证
点开那个链接，应该能看到你的 README.md 渲染成了网页。

---

## 注意事项

- **不是即时生效**：刚开的时候等 1-2 分钟才好
- **改了代码要等重新构建**：每次 push 之后，等 1 分钟左右页面才会更新
- **链接格式是固定的**：`https://你的用户名.github.io/仓库名/`

---

## 现在你有什么？

✅ 本地项目：完整的文件结构
✅ GitHub 仓库：代码托管
✅ GitHub Pages：在线可访问的文档站

评委点开链接就能看，不用下载不用 clone。
