# 项目简介（提交用）

---

## 版本一：150 字左右（推荐）

本项目完成了 Stanford Vibe Coding 系列课程的信息获取与翻译管线建设。覆盖 CS146S《现代软件开发者》、TECH 36 B、TECH 42、CS193T 四门课程，建立了"配置驱动抓取 → 分段翻译 → 术语校验 → 中文发布"的完整自动化管线。产出包括：英文原文归档、中文翻译版本（含一周完整样章）、46 条术语表、可复跑的 Python 脚本、以及 AI 处理日志与事后复盘。管线设计为配置驱动，换一门课只需修改 YAML 配置即可复跑。

---

## 版本二：100 字左右（精简版）

Stanford Vibe Coding 课程中文翻译项目。覆盖 4 门相关课程，建立了从资料抓取、分段翻译、术语校验到中文发布的完整自动化管线。产出包括：英文原文归档、中文翻译版本、统一术语表、可复跑的 Python 脚本、以及 AI 处理日志与 AAR 复盘。管线配置驱动，可复用到其他课程翻译项目。

---

## 版本三：200 字左右（详细版）

本项目完成了 Stanford Vibe Coding 系列课程的全流程信息获取与翻译管线建设。定位并归档了 4 门相关课程的一手资料：CS146S《现代软件开发者》（学分课，10 周）、TECH 36 B、TECH 42（继续教育学院，各 5 周）、CS193T Thinking with AI。建立了"配置驱动批量抓取 → 按章节分段 → AI 初译 → 术语一致性校验 → 中文发布"的完整自动化管线。产出包括：英文原文归档、中文翻译版本（含 Week 1 完整周次样章）、46 条术语表、可复跑的 Python 脚本、以及完整的 AI 处理日志与事后复盘。管线设计为配置驱动，下一批同学只需修改 YAML 配置即可复用到其他课程。
