Format: Online, 5 weeks, Thursdays 5:30–7:00pm PT

## How This Course Works
Class sessions consist mostly of lectures, with some time for student Q&A and discussion.
You learn by building. Each week has a live 90-minute session, a slide deck, and one hands-on assignment.

## Target Audience
Designed for beginners and non-programmers. No coding experience required. Basic familiarity with writing prompts for ChatGPT helps.

## Learning Objectives
1. Build and publish functional web apps, dashboards, and tools using AI-assisted development.
2. Plan a product as an MVP in MVPunk and use it as a contract that keeps the AI on track.
3. Work across the vibe coding spectrum: chatbots, no-code platforms, and professional developer tools.
4. Apply design and gamification principles that make any product feel finished.
5. Take a project from a rough demo to a shipped, shareable product.

## Tools
- Core: Claude, Lovable.dev, Google AI Studio, VibeIt.work
- Optional/advanced: GitHub (version control)
- All tools have free tiers sufficient for the course.

## Weekly Outline

### Week One: Introduction to Vibe Prompting
What vibe coding is, the vibe coding spectrum (from chatbots to professional developer tools), and how to steer a non-deterministic AI. Students build and publish their first interactive dashboard.
- Assignment 1: Vibe Code a Dashboard
- Main tool: Claude

### Week Two: From Dashboard to Product
Plan before you build: how AI processes prompts, how software development works, and turning an idea into an MVP. Students build their MVP in MVPunk and a real tool for someone else.
- Assignment 2: From Dashboard to Product (includes MVP share link)
- Main tool: MVPunk

### Week Three: The App Development Spectrum
Why chatbots hit a wall and what real apps need: databases, authentication, file storage, and server functions. Students build a working site in Lovable with a form, a database, and user accounts.
- Assignment 3: The App Development Spectrum
- Main tool: Lovable.dev

### Week Four: Making Connections
How apps connect to the outside world (APIs, MCP, JSON, and keys) and the design and gamification principles that make products feel alive. Students build a game or upgrade an existing project.
- Assignment 4: Gamification & Design Principles
- Main tool: Google AI Studio

### Week Five: Professional Web Development
What separates a demo from a shipped product: version control, the professional agentic harness (GitHub, Claude Code, agents), and the last ten percent of polish. This week is optional/advanced.
- Assignment 5: Capstone
- Tools: GitHub and Claude Code

## Assignments
Five weekly hands-on assignments, each building a real, publishable project:
1. Vibe Code a Dashboard
2. From Dashboard to Product (MVP plan in MVPunk)
3. The App Development Spectrum (working site with form, database, user accounts in Lovable)
4. Gamification & Design Principles (build a game or upgrade existing project)
5. Capstone project

Students publish their project to VibeIt and submit the link, paste a build outline, and write a short (~500 character) reflection.
