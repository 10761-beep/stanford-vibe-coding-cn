# TECH 36 B：氛围编程——用 AI 学编程（中文翻译版）

**Stanford Continuing Studies（斯坦福继续教育学院）• 2026 年秋季学期**
**原文地址：** Google Docs 教学大纲
**讲师：** Ray Villalobos
**形式：** 在线课程，共 5 周
**时间：** 每周四 17:30–19:00（太平洋时间）

---

## 课程运作方式

课堂以讲师讲授为主，穿插学生问答与讨论时间。

**学习方式：通过动手构建来学习。** 每周包含一节 90 分钟的直播课、一套幻灯片，以及一个动手实操作业。每周都要准备好构建一个真实的东西、发布它，并进行反思。

课程段落标记为"核心"或"可选/进阶"，方便学生按自己的节奏推进。

---

## 适合人群与先修要求

本课程面向初学者和非程序员，**无需任何编程经验**。不过，对 ChatGPT 等工具写提示词的基础熟悉度会有帮助。

适合：
- 想通过指挥 AI 工具来构建真实应用和网站的人
- 对 AI 驱动开发感兴趣的任何人，无论技术背景

---

## 学习目标

完成本课程后，学生将能够：

1. 使用 AI 辅助开发，构建并发布可用的 Web 应用、仪表盘和工具
2. 在 MVPunk 中将产品规划为最小可行产品（MVP），并以此作为约束 AI 方向的"契约"
3. 在氛围编程光谱上灵活工作：从聊天机器人到无代码平台，再到专业开发者工具
4. 应用设计与游戏化原则，让任何产品都有"完成感"
5. 将一个项目从粗糙的 demo 推进到可发布、可分享的成品

---

**无需购买教材**，也没有付费阅读材料。课程使用免费的在线参考工具《Vibe Glossary》作为课程词汇的通俗指南。

学生只需要一台装有现代浏览器的电脑和互联网连接。所有工作都使用免费额度的在线 AI 和 Web 开发工具完成。

## 每周课程大纲

### 第一周：氛围提示词入门

**主题：** 什么是氛围编程、氛围编程光谱（从聊天机器人到专业开发者工具）、如何引导非确定性的 AI。

学生构建并发布他们的第一个交互式仪表盘。

- **作业 1：** 氛围编程做一个仪表盘
- **演示工具：** Claude

---

### 第二周：从仪表盘到产品

**主题：** 先规划再构建：AI 如何处理提示词、软件开发是怎么回事、如何把一个想法变成 MVP。

学生在 MVPunk 中构建自己的 MVP，并为别人做一个真实可用的工具。

- **作业 2：** 从仪表盘到产品（需提交 MVP 分享链接）
- **演示工具：** MVPunk

---

### 第三周：应用开发光谱

**主题：** 为什么聊天机器人会遇到瓶颈，真正的应用需要什么：数据库、认证、文件存储和服务器函数。

学生在 Lovable 中构建一个可用的网站，包含表单、数据库和用户账户。

- **作业 3：** 应用开发光谱
- **演示工具：** Lovable.dev

---

### 第四周：建立连接

**主题：** 应用如何连接外部世界（API、MCP、JSON 和密钥），以及让产品"活起来"的设计与游戏化原则。

学生构建一个游戏，或升级一个已有项目。

- **作业 4：** 游戏化与设计原则
- **演示工具：** Google AI Studio

---

### 第五周：专业 Web 开发

**主题：** 是什么让 demo 区别于成品：版本控制、专业智能体工具链（GitHub、Claude Code、agents），以及最后 10% 的打磨。

本周为可选/进阶内容。

- **作业 5：** 结业项目（Capstone）
- **工具：** GitHub 和 Claude Code

---

## 作业与课程要求

本课程包含：
- Canvas 上发布的阅读材料和课程资料
- 作业/课后练习
- 期末作业/项目/论文
- 讲师对作业的反馈

共五个每周实操作业，每个都构建一个真实的、可发布的项目：

1. 氛围编程做一个仪表盘
2. 从仪表盘到产品（含 MVPunk 中构建的 MVP 计划）
3. 应用开发光谱（在 Lovable 中完成带表单、数据库、用户账户的可用网站）
4. 游戏化与设计原则（做一个游戏或升级已有项目）
5. 结业项目

**提交方式：** 学生将项目发布到 VibeIt，提交链接，附上构建大纲，并写一段约 500 字的反思。作业 2 还需提交 MVP 分享链接。学生将收到讲师对提交作业的反馈。

这不是小组项目课程，每个学生独立完成自己的作品。结业项目即期末作业。
